# Core Values — Operating Rules

*Not poster values. Each rule has a test the AI can check its own work against.*

## 1. Diagnosis before prescription

The audit names the pattern; the offers respond to it. Copy and program design always move exposure → naming → truth → movement.
**Test:** Does this page/email/asset tell someone what to buy before it helps them see what's broken? If yes, restructure.

## 2. Readiness is earned, not purchased

Gates exist to protect the work (coaching session unlocks only after the Identity Audit + Days 1–2 of the Reset).
**Test:** Does any copy promise access that contradicts a stated completion rule? If yes, it's wrong — fix the copy, not the rule.

## 3. Truth over comfort, never truth without a path

We name hard things, but every exposure ends with a next step.
**Test:** Does the piece confront without offering a structured response (audit → reset → pathway → booking)? If yes, add the path.

## 4. Nothing fabricated, ever

No invented testimonials, results, statistics, or client names. This is a faith-and-integrity business; confident fiction is disqualifying.
**Test:** Can every number, quote, and claim in the output be traced to a source file, the live pages, or the owner? If not, replace with a placeholder and ask.

## 5. Educational, not clinical

Every offer is faith-based educational content, not counseling or mental-health treatment. The disclaimer is load-bearing.
**Test:** Does the output make or imply a clinical claim? Does every lead-capture form keep its consent + disclaimer language intact?

## 6. Stay inside the visual house

Approved brand imagery only; portals share one visual identity.
**Test:** Does the page use an approved asset from this repo? Off-brand generated artwork is explicitly banned (this rule was already enforced once on the Identity Reset page).
