# clients/

One folder per booking client or engagement (churches, ministries, corporate clients, coaching clients), four files each:

```
clients/{name}/
├── profile.md      - Who they are, their organization, goals
├── rules.md        - Hard rules for this client (compliance, approvals, bans)
├── preferences.md  - Style, tone, formatting, pet peeves
└── history.md      - Every engagement, outcome, and lesson, dated
```

Before any client work, load that client's folder. After every meaningful interaction, add a dated entry to history.md — that file is the institutional memory.

Start with the top five: pull names from the Book Kelly Inquiries pipeline and past engagements.
