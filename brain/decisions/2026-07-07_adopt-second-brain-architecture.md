# Decision: Adopt the second-brain (DOE) architecture for this repo

**Date:** 2026-07-07 · **Source:** owner request, following the DobotAI "Second Brain Blueprint" (Doby Lanete, 2026-07-05)

We decided to restructure this repo from a flat folder of portal pages into a business brain **because** every AI session was starting from zero — no persistent context on the brand, offers, gating rules, or past mistakes.

Structure: CLAUDE.md constitution + context/ + directives/ + execution/ + skills/ + clients/ + brain/ + sources/. The portal HTML files remain the production delivery layer.

First three directives chosen from the actual most-repeated workflows in git history: portal page updates, payment updates, new portal pages.
